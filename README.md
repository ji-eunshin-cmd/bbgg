# 디스코드 가계부 봇

Python discord.py + SQLite로 만든 개인별 가계부 봇입니다. Python 3.11 또는 3.12를 권장합니다.
기록은 서버와 사용자별로 분리되며, 모든 응답은 실행한 사용자에게만 보입니다.

## 1. 봇 준비

1. https://discord.com/developers/applications 에서 애플리케이션을 만들고 Bot 메뉴에서 봇 토큰을 발급합니다.
2. Installation 또는 OAuth2 URL Generator에서 `bot`, `applications.commands` 범위를 선택하고 서버에 설치합니다. 서버 설치 권한이 있는 계정이 필요합니다.
3. 채널 보기, 메시지 보내기, 링크 임베드 권한을 허용합니다. 관리자 권한과 Message Content Intent는 필요하지 않습니다.
4. 테스트 서버 ID는 Discord 설정 → 고급 → 개발자 모드를 켠 다음 서버 우클릭 → ID 복사로 확인할 수 있습니다.

## 2. 설치 및 실행

ZIP을 압축 해제하고 `bot.py`가 있는 폴더에서 터미널을 엽니다.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Python 3.11을 설치했다면 첫 줄을 `py -3.11 -m venv .venv`로 바꿉니다.
`.env` 파일을 편집해 `DISCORD_TOKEN`에 실제 봇 토큰을 넣습니다. 빠르게 확인하려면 `DISCORD_GUILD_ID`에 테스트 서버 ID를 넣으세요.

```powershell
.\.venv\Scripts\python.exe bot.py
```

macOS / Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# .env를 편집한 뒤 실행
.venv/bin/python bot.py
```

실행 중인 터미널을 유지해야 봇이 작동합니다. 종료는 Ctrl+C입니다. 별도 웹 서버는 필요하지 않습니다.

## 3. 사용법

| 명령 | 동작 |
|---|---|
| `/가계부 입력` | 날짜·항목·금액 모달 → 빵원 성공 콤보박스 → 저장 |
| `/가계부 목록` | 현재 월 기록과 기록 ID 조회, 한 페이지 10개 |
| `/가계부 목록 기준일:2026-10-01 페이지:2` | 지정 월의 2페이지 |
| `/가계부 수정 기록번호:1` | 모달에서 수정한 뒤 빵원 여부 확인·저장 |
| `/가계부 삭제 기록번호:1` | 확인 버튼을 눌러 삭제 |
| `/가계부 주간 기준일:2026-10-26` | 해당 날짜가 속한 월요일~일요일 결산 |
| `/가계부 월간 기준일:2026-10-26` | 해당 월 1일~말일 결산 |

기준일을 생략하면 TIMEZONE 기준 오늘을 사용합니다. 날짜는 `YYYY-MM-DD`, 금액은 쉼표 없는 0 이상 정수(최대 1조 원), 항목은 1~100자입니다. 메뉴 유효시간은 5분이며 만료되면 명령을 다시 실행하세요. 저장 전 입력은 DB에 남지 않습니다.

## 4. 빵원 성공 집계 규칙

- **금액과 독립된 수동 선택**입니다. 12,000원 기록도 성공으로, 0원 기록도 미성공으로 저장할 수 있습니다. 자동 판정하지 않습니다.
- 한 날짜에 여러 기록이 있으면 **하나라도 성공으로 선택된 기록이 있는 날을 1일**로 셉니다. 같은 날 성공 기록이 3개여도 1일입니다.
- 주간·월간 총지출에는 성공 여부와 무관하게 기간 내 모든 기록의 금액이 포함됩니다.
- 지출 없는 날은 항목 `빵원 기록`, 금액 `0`, 성공을 선택해 기록할 수 있습니다.
- 마지막 성공 기록을 삭제하거나 미성공으로 수정하면 그 날짜는 성공 집계에서 빠집니다. 날짜를 수정하면 새 날짜로 집계됩니다.
- 주간은 월요일~일요일이며 월·연도를 넘어도 한 주로 집계합니다. 월간은 해당 달에 속한 날짜만 집계합니다.
- 예: 10/26에 12,000원 성공 + 3,000원 성공, 10/27에 0원 미성공 → 총 15,000원, 성공 1일.

## 5. 환경변수

| 변수 | 기본값 / 설명 |
|---|---|
| `DISCORD_TOKEN` | 필수. 봇 토큰 |
| `DISCORD_GUILD_ID` | 비우면 전역 명령 등록, 입력하면 해당 테스트 서버에 등록 |
| `DATABASE_PATH` | `data/ledger.sqlite3`, 상대 경로는 프로젝트 폴더 기준 |
| `TIMEZONE` | `Asia/Seoul`, 오늘 날짜를 결정하는 시간대 |

프로젝트 폴더의 `.env`를 읽으며, 이미 설정된 운영체제 환경변수가 우선합니다. 토큰을 다른 사람에게 보내거나 저장소에 올리지 마세요. 유출 시 개발자 포털에서 재발급합니다.

## 6. 데이터와 문제 해결

- DB는 첫 실행 시 자동 생성됩니다. 재시작해도 기록은 유지됩니다. 백업하려면 봇을 종료하고 SQLite 파일을 복사하세요. 기존 다른 프로젝트 DB의 자동 이전은 지원하지 않습니다.
- 명령이 안 보이면 서버 ID, 설치 범위, 봇과 사용자의 채널 권한을 확인하세요. 전역 등록은 표시까지 시간이 걸릴 수 있습니다. 테스트 서버 등록을 먼저 권장합니다.
- 서버 전용 등록과 전역 등록 사이를 전환하면 이전 등록이 잠시 또는 계속 남아 보일 수 있으므로 운영 방식은 한 가지로 유지하세요.
- `LoginFailure`는 토큰 확인, `Forbidden`은 서버 설치·권한 확인이 필요합니다. PC 절전/종료 시 봇도 멈춥니다.
- 동시에 수정한 오래된 화면에서는 저장을 거부합니다. 명령을 다시 실행하면 최신 기록으로 수정할 수 있습니다.

## 7. 검증

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

중복 날짜, 금액 독립 선택, 주·월 경계, 윤년, 수정·삭제, 사용자/서버 분리, 재실행 데이터 유지 및 페이지 처리를 검증합니다. 테스트는 임시 DB만 사용합니다.
실제 Discord 서버 접속·버튼 동작은 본인의 봇 토큰으로 실행한 뒤 확인해야 합니다.
